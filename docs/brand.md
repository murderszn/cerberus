# Cerberus Labs: Brand and Messaging Guidelines

## 1. Core Vision & Value Proposition
Cerberus Labs is the ultimate guardian for modern, rapid-deployment engineering teams. As developers leverage AI code assistants to ship features in minutes, security reviews are frequently compromised. Cerberus replaces slow, costly human auditing with a high-rigor, automated AI agent swarm, validating code, infrastructure, and databases against a 59-point checklist spanning nine agent domains, with a documented roadmap to 151.
* **Tagline**: `zero-trust · autonomous · always-on`
* **Key Idea**: Rigorous, real-time security certification for vibe-coded applications.

---

## 2. Target Audience Personas
* **Persona A: The Vibe-Coding Founder**: Builds application logic quickly via prompt engineering. Needs a push-button, zero-configuration audit to secure the platform and build user trust.
* **Persona B: The Compliance-Ready Lead**: Working at a fast-growing startup, tasked with achieving SOC 2, HIPAA, or GDPR compliance. Needs a formal inspection spec and scored results to identify infrastructure gaps.
* **Persona C: The Tech-Focused VC Partner**: Conducts technical due diligence on target investments. Uses Cerberus to quickly assess a startup's code quality and risk vectors.

---

## 3. Brand Tone and Voice Rules
* **Technical Rigor**: Avoid vague marketing buzzwords ("revolutionary AI"). Speak in precise technical terms (use proper nouns like "WASM Sandbox," "TLS cipher suites," "SQL Injection," "OAuth state validation").
* **High Contrast & Directness**: Do not hide vulnerabilities or fluff the results. Give raw numbers, clear letter grades (A-F), and actionable recommendation syntax.
* **Developer-Centric**: Speak like an experienced SRE/Security Engineer conducting a peer review—respectful, objective, and solution-focused.

---

## 4. Key Messaging Pillars
* **Swarm Orchestration**: The inspection is not a single linear scanner. It is a collaborative panel of 9 specialized, non-overlapping agents analyzing each layer of the target architecture.
* **Deterministic Verification**: Every vulnerability is mapped to a concrete, verifiable failure condition with a file, a line number, and a permalink pinned to the scanned commit. Checks report pass, fail, or not-applicable, so coverage is never implied where it was not measured.
* **Frictionless Integration**: No complex setup or endless agent setup dialogs. Simply paste a GitHub repository link, database connection string, or host URL, and let the swarm run.

---

## 5. Visual Identity Guidelines
* **Color Palette**: Strictly monochrome and functional. 
  - Primary Background: `#FFFFFF` (Flat white background to convey clarity and simplicity)
  - Text & Accents: `#0A0A0C` (Rich black for deep structural clarity)
  - Borders & Lines: `#E2E2E8` (Light gray dividers)
  - Dim text: `#888894` (Metadata, monospace labels)
* **Geometry**: Sharp 90-degree corners. Absolutely no border-radius. Borders are solid 1px lines. High structural contrast.
* **Typography**:
  - Headings: **Space Grotesk** (Geometrical, modern, clean)
  - Body Text: **Inter** (Highly legible, crisp sans-serif)
  - Telemetry & Code: **JetBrains Mono** (Technical, code-friendly)
