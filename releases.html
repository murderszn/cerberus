Cerberus Agent CLI

1.0.0-beta

Beta

Our terminal workbench for security research: nine specialist agents, an evidence-led review loop, and a full-screen Ink interface — direct from your shell, no browser required.

  • Ink TUI workbench plus a classic REPL
  • Specialist personas and team fan-out
  • Plan mode and accept-edits mode with ask-first approvals
  • Saved sessions, model picker, and token usage

Requirements

Python 3, plus the agent runtime dependencies in servers/requirements-agent.txt. The deterministic scanner (examine.py) stays stdlib-only and needs nothing extra.

Install

npx cerberus-agent scan .
npx cerberus-agent agent "audit this repository"

The npm launcher installs the Cerberus Python runtime into your active Python environment, then forwards commands to the CLI. It requires Node.js 18+ and Python 3.10+.

Direct Python install: pipx install "cerberus[agent] @ git+https://github.com/murderszn/cerberus.git". Scanner-only install: pipx install git+https://github.com/murderszn/cerberus.git.
